# Rehber Standardı

Bu bölüm, TÖDEB kullanım rehberlerinin ortak içerik yapısını değerlendirmek için hazırlanmış çalışma alanıdır.

Buradaki örnekler kesin şablon değildir. Yazılım ekibinden gelecek Markdown dosyaları incelendikten sonra başlıklar, sıralama ve ihtiyaç duyulmayan alanlar birlikte güncellenecektir.

## İncelenecek sayfalar

- [Örnek kullanım kılavuzu](ornek-kullanim-kilavuzu.md): Temsili bir CRM işleminin baştan sona nasıl anlatılabileceğini gösterir.
- [İçerik bileşenleri](icerik-bilesenleri.md): Mevcut sistemde kullanılabilen Markdown parçalarını ve bugünkü sınırları gösterir.
